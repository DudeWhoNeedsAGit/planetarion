# Assets

This folder contains game art and UI assets (icons, banners, backgrounds).

## Structure

- `docs/assets/prompts/` — batch prompts and AHK scripts used to generate assets
- `docs/assets/images/` — generated/exported images (PNG/SVG/WebP)
- `docs/assets/images/ships/` — ship icons
- `docs/assets/images/buildings/` — building icons
- `docs/assets/images/research/` — tech icons + research banners
- `docs/assets/images/galaxy/` — minimap frame, map markers, tooltips, backgrounds
- `docs/assets/images/combat/` — victory/defeat, debris, recycler, payout banners
- `docs/assets/images/planets/` — planet thumbnails, biome frames, capture/colonize/rename banners

## Notes

- Keep sources editable when possible (SVG/PSD/etc.) and export web-ready PNG/WebP.
- Avoid committing huge raw renders. Prefer curated selections + compressed exports.
